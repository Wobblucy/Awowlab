AwowLab Font Support
====================

AwowLab includes NotoSans-Regular.ttf which supports:
- Latin (English, Spanish, Portuguese, French, German, Italian)
- Cyrillic (Russian)

NotoSans-Regular.ttf is licensed under the SIL Open Font License 1.1 -
see OFL.txt in this folder for the full license text.

For Asian language support, you can add optional fonts:


CHINESE (Simplified) - zh_CN
----------------------------
Download: NotoSansSC-Regular.ttf
From: https://fonts.google.com/noto/specimen/Noto+Sans+SC

Place the file in this folder as: NotoSansSC-Regular.ttf


CHINESE (Traditional) - zh_TW
-----------------------------
Download: NotoSansTC-Regular.ttf
From: https://fonts.google.com/noto/specimen/Noto+Sans+TC

Place the file in this folder as: NotoSansTC-Regular.ttf


KOREAN - ko_KR
--------------
Download: NotoSansKR-Regular.ttf
From: https://fonts.google.com/noto/specimen/Noto+Sans+KR

Place the file in this folder as: NotoSansKR-Regular.ttf


ALTERNATIVE: Use Windows System Fonts
-------------------------------------
If you don't want to download fonts, AwowLab will try to use
Windows system fonts as fallback:

- Chinese: Microsoft YaHei (msyh.ttc)
- Korean: Malgun Gothic (malgun.ttf)

These are included with Windows and should work automatically.


After adding fonts, restart AwowLab for changes to take effect.
